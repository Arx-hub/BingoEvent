## Guide Purpose

These guides serve to:
- **Document implementations** - What was built and how
- **Track changes** - Understand modifications over time
- **Provide context** - Why decisions were made
- **Enable maintenance** - Help future developers understand the code
- **Facilitate onboarding** - Help new team members get up to speed
